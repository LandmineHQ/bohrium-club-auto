远程登录玻尔账号

凭证仅持久化保存在服务器本地 data/state.json

由服务端向 platform.bohrium.com 申请官方微信登录二维码，无图形验证码，最适合远程服务器。

点击下方按钮生成二维码
等待发起扫码

选择第三方渠道打开玻尔官方 OAuth 授权页；授权后浏览器跳转到 login.bohrium.com 或 /auth-code，将跳转后的完整网址（含 code= 或 token=）粘贴到下方即可完成服务端登录。

OAUTH URL

支持手机号短信验证码或邮箱验证码登录（若上游风控要求图形验证码，请改用微信扫码或 Google/第三方 OAuth）。

支持手机号 / 邮箱 / 学术码（Account ID）+ 密码登录；仅当账号未触发图形验证码时可用。

从已登录 club.bohrium.com 的浏览器 Cookie 中复制 brmToken（支持直接粘贴整段 Cookie）。
