# 常见问题

### Q1：忘记管理员密码怎么办？

查看数据目录中的 `data/config.json`（容器内为 `/data/config.json`）中的 `adminPassword` 字段，或在环境变量中重新设置 `BOHRIUM_ADMIN_PASSWORD` 并重启服务。

### Q2：任务 3（文献阅读）服务器无法访问 `arxiv.org` 怎么办？

有两种零门槛方案：

1. 在设置中配置 `BOHRIUM_PROXY` 出站代理；
2. 或者提前在宿主机将若干份学术 PDF 放入数据卷的 `data/custom_pdfs/` 目录，程序会自动识别并随机抽取这些本地 PDF 上传，完全无需外网下载 arXiv。

### Q3：为什么定时任务没有准点在 `08:15:00` 触发？

默认开启了 `jitterMinutes: 15`（基于当日日期的确定性随机延迟 0~15 分钟），以模拟自然访问时间分布。如需精确到分钟触发，可在「定时与系统设置」中将随机延迟抖动设为 `0`。

### Q4：任务提交并立即取消后，状态没有立刻变成「已完成」？

玻尔后台异步消费 `query-events` 通常需要 1~5 秒延迟。点击控制台右上角 **「刷新数据」** 即可看到最新完成状态与光子到账。

### Q5：如何确认线上 Bohrium 前端有没有改版导致接口失效？

在控制台切换到 **「前端 Recon 监控」** 标签页点击 **「检测线上更新 (Diff)」**，或在命令行运行 `./bohrium-club-auto recon diff` 即可比对静态资源 SHA-256 与关键 API 契约标记。
