# Web 管理控制台

内置单页管理后台（SPA）通过 `go:embed` 直接编译进可执行文件，启动后访问 `http://<host>:8788/` 即可使用。

## 页面模块

### 1. 总览与每日任务

- **4 项核心 KPI 卡片**：剩余光子积分（含组织额度、钱包与 7 日过期预警）、知识库剩余存储容量与进度条、会员等级及功能剩余配额、今日 Web 任务完成进度与下次定时时间；
- **一键操作栏**：支持「一键领取每日任务」与「一键执行全部 Web 任务」；
- **4 项每日任务卡片**：展示奖励光子、状态徽标（未领取 / 待完成 / 已完成 / 已跳过）及每项 Web 任务的独立「领取」与「手动完成任务」触发按钮；
- **运行状态面板**：实时显示内置题库/文献池规模、本地缓存 PDF 数量、当前 Chrome User-Agent。

### 2. 积分明细与容量

- 完整展示个人/组织光子、钱包余额、7 日即将过期光子、文献检索/知识库对话/深度研究配额；
- **即将过期光子批次表**与**近期光子收支流水表**。

### 3. 执行日志

- 保留最近 200 条结构化日志（按时间倒序），详细记录每次领取、提问预览、抽中论文 ID、耗时、`workflowId`、`query-events` 上报与取消状态。

### 4. 前端 Recon 监控

- 无需登录服务器命令行，点击 **「拉取 / 更新基线 (Pull)」** 与 **「检测线上更新 (Diff)」** 即可比对线上 Bohrium 前端静态资源与关键 API 契约标记是否发生变更。

### 5. 定时与系统设置

- 在线修改每日执行时间（`HH:MM`）、时区（默认 `Asia/Shanghai`）、随机延迟抖动（分钟）、自动领取、自动续期、任务间隔秒数、立即取消延迟毫秒数、Chrome UA、出站代理以及控制台管理员密码。
