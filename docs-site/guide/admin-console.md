# Web 控制台

Web 管理面板基于 **React + Vite + TypeScript + Tailwind CSS + shadcn/ui** 构建，编译产物通过 `go:embed` 内置到 Go 二进制中，启动后访问 `http://<host>:8788/` 即可使用。

## 页面结构

### 01 多账号与签到

- 顶部 4 项聚合指标：在线账号数、全账号总光子余额、今日多账号签到进度、聚焦账号存储容量；
- **多账号管理表**：展示账号备注/昵称/UID、个人与组织光子余额、Token 有效期、每日随机签到计划与独立开关、路由池权重、单项操作（聚焦查看、立即签到、修改备注、Token 续期、删除）；
- **单账号每日任务**：支持切换聚焦账号，执行一键领取、全部任务执行或单项任务触发；
- **运行态概览**：展示内置题库规模、调度状态与当前出站 User-Agent。

### 02 积分与容量

- 按所选账号展示个人光子、组织余额、钱包余额、7 日即将过期光子、知识库容量及各项功能配额；
- 展示即将过期光子批次表与近期光子流水表。

### 03 OpenAI 路由池

- **拖拽路由池看板**：左侧为未入池候补账号，右侧为活跃 OpenAI 路由池，支持拖拽入池/移出/排序以及实时权重进度条；
- **活跃会话绑定表**：展示 SQLite 中 7 天有效期的 `session_hash → 账号` 映射、命中次数与剩余 TTL，支持单条解绑或全部清空；
- **网关配置与 API Key 管理**：开关网关、无 Key 访问、计费预检、SciMaster 系统提示词、默认模型、CORS，以及 API Key 增删启停和 cURL 示例复制；
- **模型目录与在线调试（Playground）**：实时拉取 SciX 模型目录、单模型预检，以及支持 Chat Completions / Responses API 流式与非流式测试的在线调试器。

### 04 执行日志

- 读取 SQLite 中保留的最近 1000 条执行与操作日志，支持按账号筛选。

### 05 前端 Recon

- 查看本地基线快照状态与契约标记，支持触发 Pull（更新基线）与 Diff（比对上游变化）。

### 06 定时与设置

- 配置多账号随机波动签到基准时间、时区、波动窗口（0–720 分钟）、自动领取、自动续期、任务间隔、取消延迟、User-Agent、出站代理与管理员密码。
