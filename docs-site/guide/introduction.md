# 功能概述

本程序是一套自托管 Go 服务，集成了多账号管理、每日任务定时调度、资产监控、OpenAI 兼容路由池与内置 Web 管理控制台。

## 主要功能

1. **多账号管理与远程登录**：支持在控制台添加多个账号（微信扫码、OAuth、验证码、密码或导入 `brmToken`），所有账号隔离存储在本地 SQLite 数据库（`data/bohrium.db`）中，并自动分配独立 `storeId` 与后台续期。
2. **随机波动每日任务**：
   - 支持手动一键领取、单项触发与多账号错峰自动签到；
   - 覆盖 Web 端、客户端协议任务、文献阅读与学术写作全部 4 项每日任务；
   - 触发并完成上报后及时取消生成流程，不调用已废弃的旧版签到接口。
3. **OpenAI 兼容混合路由池**：
   - 新添加的账号默认不进入路由池，需在控制台手动拖入后才参与 `/v1/*` 流量路由；
   - 新会话按有效余额（个人光子 + 组织余额）比例加权选择健康账号，并在 SQLite 中绑定最长 7 天；
   - 首包前遇到 401/402 自动冷却并切换其他健康账号重绑。
4. **单文件二进制与模块化前端**：管理面板使用 React + Vite + TypeScript + Tailwind CSS + shadcn/ui 构建至 `web/dist`，再由 Go `go:embed` 打包进静态单文件二进制（`CGO_ENABLED=0`）。

## 每日任务执行方式

| 序号 | 任务 | 执行链路 | 终止方式 |
| --- | --- | --- | --- |
| 1 | 体验玻尔科学空间「Web端」 | 随机抽取题库发起 Web 聊天并上报 `query-events` | 调用 `/cancel` 终止 |
| 2 | 体验玻尔科学空间「客户端」 | 桌面端协议 `/billing/preflight` + `/scix/llm/chat/completions`（含完整 16 项 tools）并上报 `query-events` | 受理后立即取消 SSE 流 |
| 3 | 体验玻尔「文献阅读」 | 上传缓存或自定义 PDF → 登记 Reader → 发起提问并上报 `query-events` | 调用 `/cancel` 终止 |
| 4 | 体验玻尔「学术写作」 | 随机抽取写作题库发起提问并上报 `query-events` | 调用 `/cancel` 终止 |
