# 项目介绍

**Bohrium Club Auto** 是一套面向 [玻尔用户社区 (`club.bohrium.com`)](https://club.bohrium.com/) 的自托管 **Go** 自动化服务与管理控制台。

## 核心解决的问题

1. **服务器无人值守远程登录**：直接在 Linux/Docker 服务器部署后，在控制台弹窗用微信扫码即可完成登录，并通过 `refresh_token` 保持会话长期有效。
2. **剩余积分与容量一目了然**：统一聚合光子余额、7 日内过期明细、近期流水、会员各功能配额与知识库剩余存储空间。
3. **每日任务精准执行**：
   - 提供 **「一键领取每日任务」** 按钮与定时自动领取；
   - 自动跳过第 2 项桌面客户端任务（`体验玻尔科学空间「客户端」`）；
   - **绝不调用**已废弃的旧版 200 光子签到接口（`/bohrapi/v1/account/user/integral_receive`）；
   - 其余 3 项 Web 任务通过真实产品 API 随机抽题/抽文献发起提问，在上报 `query-events` 后**立即终止工作流（`cancelWorkflow`）**。
4. **单文件交付 & 极简镜像**：Go 1.24 零第三方依赖编译，前端仪表盘、870 条题库、100 篇文献目录与时区数据全部通过 `go:embed` 内嵌进约 **7.5 MB** 的单文件二进制，Alpine 运行镜像仅约 **15 MB**。
